# Real-Time Pedestrian & Vehicle Detection Using OpenCV

This project demonstrates a **real-time pedestrian and vehicle detection system** using **OpenCV** and **Haar cascades** to identify cars and pedestrians in video streams. The system is designed to detect and classify vehicles and pedestrians efficiently, making it ideal for applications like **traffic monitoring**, **surveillance**, and **autonomous vehicles**.

---

## 📊 Business Problem

As urban areas continue to grow, the need for **automated traffic monitoring** and **public safety** systems is more critical than ever. Detecting pedestrians and vehicles in real-time can significantly enhance traffic management, surveillance, and situational awareness in smart cities.

This project addresses the challenge of detecting pedestrians and vehicles in video feeds, enabling:

- **Traffic monitoring** to improve urban mobility and congestion control
- **Surveillance systems** for enhanced public safety and security
- **Autonomous vehicles** for safer navigation and decision-making

---

## 🧠 Project Overview

The pedestrian and vehicle detection system utilizes **Haar cascade classifiers**, a machine learning-based object detection method, to identify vehicles and pedestrians. The system processes real-time video feeds, draws bounding boxes around detected objects, and provides insights into traffic flow and safety.

Key features include:
- **Haar Cascade Classifiers** for detecting vehicles and full-body pedestrians
- **Real-time detection** optimized for video stream processing
- **Bounding boxes** drawn around detected objects for visualization
